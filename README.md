Follow the steps below to view this project.

1. Download "player_engagement_data.csv"
2. Download the latest version of the .ipynb file
3. Navigate to https://jupyter.org/try-jupyter/notebooks/?path=notebooks/Intro.ipynb
4. Click "File"
5. Click "Open..."
6. Click "Upload"
7. Upload the .csv and .ipynb files
8. Double-click the .ipynb file once uploaded. This will open the file in Jupyter's web application.
9. Click the "forward" symbol (two triangles with points facing to the right) to restart the kernel and run all cells
10. Peruse the project!
